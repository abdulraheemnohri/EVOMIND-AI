Linux systemd auto-start

Run this once from the repository directory after installation. It creates a per-user service and enables it.

bash scripts/install_autostart.sh

Android Debian / Termux

A proot Debian environment generally does not run systemd. Install Termux:Boot, then run the Termux launcher installer from the Termux host shell.

bash scripts/install_android_termux_boot.sh

Android battery management may still stop background processes. See README for limitations and service management.
